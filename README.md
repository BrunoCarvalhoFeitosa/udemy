## Iniciando o projeto

Primeiramente será necessário clonar este projeto em (https://github.com/BrunoCarvalhoFeitosa/udemy.git), após o download será necessário abrir este projeto no seu editor e no terminal digitar yarn install, posteriormente é só rodar em seu terminal o comando yarn dev, após isso, a página será aberta em seu navegador.

### Pré-requisitos

* npm
  ```sh
  yarn install npm@latest -g
  ```

### Instalação

1. Clone o repositório
   ```sh
   git clone https://github.com/BrunoCarvalhoFeitosa/udemy.git
   ```
2. Instale os pacotes do NPM
   ```sh
   yarn install
   ```
   
3. Inicie o projeto
   ```sh
   yarn dev
   ```
